# WorkBuddy 每日积分领取

在当前已登录的 Windows WorkBuddy 中处理 Buddy 加油站的每日奖励。用户要求查询时只读取状态。用户要求签到或领取时，先读余额，再操作并核对差额。

## 找到正确的卡片

1. 优先使用可用的 `agent-desktop` Windows 工具，按 `WorkBuddy.exe` 枚举窗口并限定后续操作的窗口。没有主窗口时，优先通过已确认的 WorkBuddy 开始菜单或桌面快捷方式唤出。若启动提示多个进程但列表没有窗口，现有实例可能藏在托盘，重新打开已确认的快捷方式通常可以唤出。按宿主权限使用可用的桌面工具，登录或必须由用户处理的提示交给用户。
2. 在主窗口左下角找到「Buddy 加油站」轮播卡片，同时确认「每日可领」的积分数和领取按钮的状态。轮播切换时，重新定位目标卡片后再操作。头像菜单的「去邀约」和侧栏的「做任务赢积分好礼」分别进入邀请活动和成长计划。根据卡片上的「每日可领」识别本任务的入口。无障碍树缺失、超时或只返回部分文字时，用当前目标窗口截图确认。

## 先读余额，再领取

1. 打开左下角头像菜单。点「积分余额」卡片可打开单独的 WorkBuddy 设置窗口。进入「套餐与积分」，优先读页面顶部「平台奖励积分」余额。若无法可靠读取该字段，可用头像菜单的「积分余额」，前后均读取同一账号的同一字段。需要刷新时使用头像菜单余额旁的「刷新」，等待读数稳定。设置窗口不一定自动到前台，重新枚举窗口并用窗口内容确认。
2. 记录领取前余额和卡片显示的奖励数。使用数字的实际精度，处理千位分隔符，保留小数。无法可靠读取领取前余额或奖励数时，停在领取前，并报告缺失项。
3. 返回主窗口并重新核对同一张卡片。卡片仍显示可领取时，只点击这张卡片上的领取按钮。若工具提示送达不明，先观察卡片、余额或记录。只有确认动作未送达且卡片仍可领时，才重新定位后尝试。
4. 确认目标卡片显示「今日已领取」，再重新读取领取前选定的余额字段。若读数未更新，等待刷新完成后有限次复查，刷新与重新读取均属于核验。计算 `领取后余额 - 领取前余额`。只有卡片显示已领取且差额精确等于奖励积分时，才报告「已核实到账」。报告应包含奖励数、前后余额与实际增量。差额不符或读数、按钮状态缺失时，列出已取得的证据并说明哪项未能核验。

## 打开时已领取

- 卡片一开始就显示「今日已领取」时，直接核对状态。可在「套餐与积分 → 积分明细 → 积分概览 → 平台奖励积分 → 查看明细」查找来源为「Buddy 加油站签到」的记录。只有记录明确标出可核对的领取日期时，才将它归到对应日期。明细里的到期时间是有效期信息，「剩余」是该笔记录当前可用的积分。
- 缺少本次领取前的可信读数时，报告「今日已领取，无法核对本次余额增量」。可附上已核实的记录和当前余额。查询请求同样适用这一证据标准。
